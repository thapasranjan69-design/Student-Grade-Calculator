🎓 Student Grade Calculator

A beginner-friendly Python project that calculates student marks, average, grades and pass/fail results.

🚀 Features

- Accepts student name.
- Takes marks for five subjects.
- Calculates total marks and average.
- Assigns grades based on average.
- Displays PASS or FAIL status.

🛠️ Technologies Used

- Python 3
- Basic Python concepts
- Loops and conditional statements
- Lists and built-in functions

▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

python main.py
